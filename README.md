# Sales Data Analytics System
This Python system processes messy e-commerce sales data, performs strict data cleaning, and generates business reports.

## How to Run
From the parent directory, use the following command:
`python -m sales-analytics-system.main`

## Project Structure
- `utils/`: Core logic for data processing and API interaction.
- `data/`: Raw sales transaction files.
- `output/`: Finalized analytics reports.
